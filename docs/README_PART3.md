# Bunny - Part 3 (Telegram Interface)

This part connects Bunny to a Telegram bot using long polling.

## How it works alongside FastAPI
The Telegram bot runs as a separate Python process alongside the FastAPI server. 
- **Process 1**: `uvicorn app.main:app` (Handles the database and LM Studio)
- **Process 2**: `python -m app.telegram_bot` (Handles Telegram messages and routes them to Process 1)

Both processes operate locally and securely without exposing your IP or ports to the internet.

## 1. Create the Bot via @BotFather
1. Open Telegram and search for `@BotFather`.
2. Start a chat and send `/newbot`.
3. Give it a display name (e.g., `My Bunny Bot`) and a username ending in `bot` (e.g., `my_bunny_999_bot`).
4. BotFather will reply with an **HTTP API Token**. Save this token.

## 2. Find Your Telegram Chat ID
You need your personal Chat ID so the bot ONLY responds to you.
1. In Telegram, search for `@userinfobot` or `@RawDataBot`.
2. Send a message to it, and it will reply with your `Id` (a number like `123456789`).
3. Save this ID.

## 3. Set Environment Variables
The bot requires two variables: `TELEGRAM_BOT_TOKEN` and `ALLOWED_TELEGRAM_CHAT_ID`.

### Option A: `.env` file (Recommended for permanent use)
Create a `.env` file in the `bunny/` folder (it is already in `.gitignore`) and add:
```
TELEGRAM_BOT_TOKEN="your_token_here"
ALLOWED_TELEGRAM_CHAT_ID="your_chat_id_here"
```

### Option B: PowerShell session
If you prefer not to use a `.env` file, you can set them in your active PowerShell session before running the bot:
```powershell
$env:TELEGRAM_BOT_TOKEN="your_token_here"
$env:ALLOWED_TELEGRAM_CHAT_ID="your_chat_id_here"
```

## 4. Run Both Processes and Test
You need **two** terminal windows open in the `bunny/` folder, both with the virtual environment activated (`venv\Scripts\activate`).

**Terminal 1 (FastAPI Backend):**
```cmd
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

**Terminal 2 (Telegram Bot):**
```cmd
python -m app.telegram_bot
```

### Testing the Bot
1. Open Telegram and message your new bot.
2. Ensure you get a real reply generated by your local LM Studio.
3. **Security Check**: Ask a friend (or use an alternate Telegram account) to message the bot. **Confirm they do NOT get a response.** This proves the chat-id allowlist is working perfectly and rejecting unauthorized access.
